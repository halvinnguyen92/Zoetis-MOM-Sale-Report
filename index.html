⚙️ Cần cấu hình Google Sheets
Nhập URL CSV của Google Sheets để report tự động đọc data mới nhất mỗi khi mở.

Cách lấy URL:
1. Mở Google Sheets → File → Share → Publish to web
2. Chọn sheet "orders" → Format: Comma-separated values (.csv)
3. Nhấn Publish → Copy link → Paste vào ô trên
